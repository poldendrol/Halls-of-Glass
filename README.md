# The Hall of Glass

A short browser roguelike set in the Reverse, from the *Clockwork, Lord of Time* campaign in Velloran.
You climb Lock Keep's endless stair to stop Clockwork, and each floor teaches you a piece of who he used to be. Every death adds a glass coffin that remembers.

It's a single static page (`index.html`) with no build step. `render.yaml` deploys it as a free Render static site.
